# Crescent Client — Fabric Mod

Initial client-mod foundation for Minecraft 1.21.1.

## Requirements
- Java 21
- Gradle (the GitHub Actions build uses Gradle setup)

## Build
```bash
gradle build
```

The mod JAR is written to `build/libs/crescent-client-0.1.0.jar`.

## Initial foundation
- Right Shift opens the Crescent settings screen.
- FPS HUD toggle.
- Basic WASD keystrokes HUD toggle.

This is an early foundation, not the complete planned feature set. Account integration, skin management, capes, CPS, draggable HUD editor, persistence, and the full visual design are subsequent milestones.
